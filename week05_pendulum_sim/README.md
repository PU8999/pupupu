# 单摆简谐振动模拟器 · Pendulum Simulator

一个基于 **Canvas + requestAnimationFrame** 的实时单摆物理仿真，零依赖、单文件即可运行。

## 特性

- **严格非线性物理模型**：积分方程 `θ'' = -(g/L)·sin θ - c·θ'`，不取小角近似，保留真实摆动特征。
- **半隐式（辛）欧拉积分 + 子步进**：每帧推进 1/15 s 物理时间、分 4 个子步，数值稳定不发散。
- **实时参数交互面板**（画布下方）：
  - 摆长 `L`：`100 ~ 350 px`
  - 重力 `g`：`1 ~ 25`
  - 阻尼 `c`：`0.000 ~ 0.010`（欠阻尼，自然衰减）
- **重置按钮**：一键将摆球精准复位到 `45°` 初始状态。
- **深色质感 HUD**：左侧参数面板、右侧实时遥测（θ / ω / v / t），含拖影式运动模糊与球面高光渲染。

## 运行方式

无需构建，直接打开 `index.html` 即可：

```bash
# 方式一：浏览器直接打开
open index.html        # macOS
# 或双击 index.html

# 方式二：本地静态服务器（推荐，避免个别浏览器的 file:// 限制）
python3 -m http.server 8000
# 然后访问 http://localhost:8000
```

## 使用说明

1. 拖动三个滑块，物理模拟即时响应（摆长 / 重力 / 阻尼实时变化）。
2. 阻尼设为 `0` 时为无阻尼等幅摆动；调大后摆幅自然衰减。
3. 点击 **重置摆动**，摆球立即回到 45° 初始角度。

## 技术栈

- 原生 HTML5 Canvas 2D
- 原生 JavaScript（ES6+，IIFE 作用域）
- 无任何第三方依赖
